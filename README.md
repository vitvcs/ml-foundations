\## General Overview



This repository documents a structured plan for training in applied AI, with a focus on

conceptual understanding, implementation from scratch, and critical analysis of data

and models.



\## Main Question



How can one develop a solid and independent foundation in applied AI without relying

on AI-generated code?



\## Methodology

* Manual implementation whenever possible  
* Use of AI only for conceptual review  
* Daily writing of technical reflections
